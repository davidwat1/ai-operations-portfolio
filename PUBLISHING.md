# Publishing checklist

1. Review every file for personal, proprietary or confidential information.
2. Create a GitHub repository named `ai-operations-portfolio` (public only after review).
3. Upload these files to the repository's `main` branch.
4. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
5. Verify the live site and its links before sharing publicly.
6. Add the verified live URL to LinkedIn Featured; publish a case study post only after final review.

GitHub Pages publishes public websites. Do not include private data even if the repository is private.
