# David Watkins — Applied AI & Operations Portfolio

A public-safe, static portfolio demonstrating executive-level AI operations design and responsible automation. This repository is a **portfolio draft**, not a claim that every illustrated system is deployed.

## Contents
- `index.html`: executive portfolio landing page
- `case-studies/agentic-job-search.html`: first case study
- `METRICS.md`: measurement definitions and evidence gates
- `PUBLISHING.md`: deployment instructions

## Local preview
From the repository directory, run `python -m http.server 8000` and open `http://localhost:8000`.

## Security and integrity
Never commit personal correspondence, resumes containing contact information, API tokens, private automation instructions, client data, or real applicant records. Synthetic demonstrations must be explicitly labeled. All quantitative outcomes require independently checkable evidence.
